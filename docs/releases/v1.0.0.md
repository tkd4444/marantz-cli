# Marantz CLI v1.0.0

Initial release of the shared macOS/Linux command-line utility for compatible
Marantz network amplifiers and receivers.

## Functionality

- Automatic IPv4 SSDP discovery, identity verification, exact device selection,
  native cache paths and direct-host/port overrides.
- Read-only status, identity and capability observations; power, integer volume,
  relative volume and mute commands; input queries; soft standby/on cycling.
- One CR-terminated protocol primitive per short-lived TCP connection, bounded
  waits, preflight checks and state confirmation without ambiguous setter retries.
- Bash/Python standard-library implementation, help, manual and user-local/custom
  prefix installation, atomic upgrades and conservative uninstall.

## Hardware and platforms

Developed and tested on Marantz MODEL 40n. Compatibility with other Marantz devices is experimental or unverified unless explicitly documented.

MODEL 40n query/discovery observations are the physical regression evidence.
Other models, simulations and manufacturer documents do not certify physical
setters, safe listening ranges or wake/audio timing. See the compatibility matrix.

Supports macOS Intel/Apple Silicon and Linux AMD64/ARM64. The platform report
separates native macOS, official Ubuntu 24.04/Debian 12 container results and
GitHub-hosted CI. Windows and other Linux distributions remain unverified.

## Installation

From an extracted source archive or checkout:

```sh
./install.sh --prefix "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
marantz --help
man -M "$HOME/.local/share/man" marantz
```

Use `./uninstall.sh --prefix "$HOME/.local"` to remove the installed files.
Python 3.9+, Bash 3.2+, awk and standard system utilities are required. No netcat
variant, third-party Python package, background service or setup file is needed.

## Known limitations and security

- Discovery is IPv4; multicast may be blocked by VPNs, VLANs, firewalls or VM
  networking. Use a directly reachable host or freshly validated cached identity.
- Input is read-only. No factory reset, zone/source translation, HEOS JSON control
  or serial transport is implemented. Numeric volume is a protocol code, not a
  universal percentage or dB value.
- A valid query does not certify setters. Unknown replies block corresponding
  built-in writes; owners must verify their model and choose a safe listening level.
- Receiver control may be unauthenticated and is unencrypted. Use a trusted LAN;
  never expose the receiver's TCP control port directly to the internet.
- A timeout can leave state changed. Inspect status before manually repeating an
  ambiguous command; the CLI does not replay it automatically.

Read README, SECURITY, the compatibility matrix and platform verification report
before operating an unfamiliar receiver. No new physical receiver tests are
claimed by the release automation.
